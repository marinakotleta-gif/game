# Утиная бухта — Telegram Mini App prototype

Небольшой русскоязычный игровой прототип: тапай утку, собирай ракушки, улучшай бухту, выполняй ежедневное задание и приглашай друзей. Интерфейс адаптирован для мобильного Telegram Web App и браузера.

## Запуск

Открой `index.html` через локальный статический сервер или размести три файла (`index.html`, `styles.css`, `game.js`) на HTTPS-хостинге. Для запуска внутри Telegram создай бота через BotFather, настрой Mini App на HTTPS URL и укажи домен. Вне Telegram игра работает как браузерный прототип. Имя бота можно передать как `window.DUCK_HARBOR_BOT_USERNAME` до загрузки `game.js`.

## Что уже работает

- Тап-механика с энергией и её восстановлением.
- Монеты, уровни, улучше��ия и пассивный доход.
- Ежедневный бонус и задание на 10 тапов.
- Приглашение через Telegram share URL.
- Интерфейс витрины для косметического предмета за Telegram Stars.
- Сохранение локального прогресса в `localStorage`.

## Перед публичным запуском

Это клиентский MVP: локальные данные можно изменить, поэтому не используй их для ценных наград, токенов или денежных выплат. Для реальной монетизации и честной экономики нужен backend:

1. Валидировать `Telegram.WebApp.initData` на сервере и получать пользователя только из проверенных данных.
2. Хранить баланс, энергию, задания и реферальные связи на сервере; ограничивать частоту игровых действий.
3. Создавать invoice link для Telegram Stars только сервером. Включить интеграцию можно, задав до загрузки `game.js` `window.DUCK_HARBOR_INVOICE_ENDPOINT` — endpoint д��лжен принять `itemId` и `initData` и вернуть `{ "invoiceLink": "https://..." }`.
4. Выдавать предмет только после подтверждения успешного платежа на сервере; не считать клиентский callback `openInvoice` источником истины.
5. Для рефералов обрабатывать уникальные start-параметры на backend, чтобы нельзя было начислять бонусы повторно.

Витрина сейчас намеренно отключена без настроенного endpoint. Прототип использует оригинальное название и визуальный стиль, а не копирует оформление или бренд других игр.
